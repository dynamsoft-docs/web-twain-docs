# Error Troubleshooting

## Error message – Your Dynamic Web TWAIN product key expired

### Symptom

You see the following pop-up

![Product key expired](/assets/imgs/product-key-expired.png)

### Cause

The trial product key has expired.

### Resolution

Follow the instructions on that pop-up which are:
1. Request a new trial product key <a href="https://www.dynamsoft.com/customer/license/trialLicense" target="_blank">here</a>. Refer to [Using License Keys](/_articles/general-usage/license.md){:target="_blank"} for how to configure the new ProductKey in your project
2. Do a hard refresh or clear cache in your browser to make sure the new ProductKey is used
